## Técnico

- Publicado en Vercel desde la rama `main`.
- La dirección vieja (`ragepay.github.io/iPortafolio-Benjamin-Peyraga`) redirige a la nueva.
- Para verlo localmente: `python -m http.server` y abrir http://localhost:8000.
